# ShadowSlate 实拍投影台

用于桌面投影照片里的暗区检查。画框时保留真实桌面，避开投影物体。像素换算可使用照片里的已知标尺。

1. 打开注明为合成的练习，或导入单张 PNG、JPEG、TIFF、BMP、WebP。
2. 设定原片测量框和判断方式：
   - **同列纸色参照（默认）**：测量框最上、最下各 8 行是未挡光的参照纸条。每一列只用本列上下条的原片像素；两条各自至少有 4 个 RGB 三通道都在 1–254 的实拍像素，该列才可用。可用列在测量点高度按上下条亮度线性插值出当地纸色，框内原片亮度除以当地纸色、低于填写的阴影比例才记为阴影。任一条像素不足的列，其中测量点标「待核」，不借用旁列。
   - **全框亮度阈**：原有方式，框内亮度不超过暗区亮度上限即记暗区，可随时切回。
3. 直接填原片行，或用「取读数行」在图上定位。保存后查看实际行亮度（截线始终显示真实源亮度）与阴影覆盖。
4. 覆盖比例按两条参照纸之间有证据的像素计：阴影面积只算真实认成阴影的点，待核像素既不算阴影也不进分母，并单独给出待核数。
5. 下载原坐标的 CSV、PNG 或证据 ZIP。截线、点读、CSV、PNG 校样使用同一个判断；也可以把原照片直接交给照片准备。

`docker compose up --build -d --wait` 默认本机端口19918。在 Python 3.11 虚拟环境装好 `requirements.txt` 后也可执行 `./start.sh`。数据保存在独立数据卷或普通启动目录。
