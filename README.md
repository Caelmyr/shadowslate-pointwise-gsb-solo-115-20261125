# ShadowSlate 实拍投影台

用于桌面投影照片里的暗区检查。画框时保留真实桌面，避开投影物体。像素换算可使用照片里的已知标尺。

1. 打开注明为合成的练习，或导入单张 PNG、JPEG、TIFF、BMP、WebP。
2. 设定原片测量框和暗区亮度上限。当前暗区为框内达到该亮度阈的像素。
3. 直接填原片行，或用「取读数行」在图上定位。保存后查看实际行亮度与暗区覆盖。
4. 用「取影边」在读数行上点一处影边位置：在该点左右各32列内找实际暗端和亮端，每端至少4个连续实拍像素、端内最亮与最暗相差不超过6，两端代表亮度至少差20。按两端的实际亮度算10%和90%，只在有相邻原片像素夹住的位置读取交点与毫米宽度，不朝画外推。找不到完整两端时提示待核；两段暗端都成立时，先取离所点位置更近的边，再比较端内亮度稳定程度。
5. 采用影边后，原来的截线标出这两个过渡坐标；在原片点读任意像素仍显示该处原亮度，并注明它落在本次过渡的哪一边或中间。影边读数只对采用时那一原片行生效，其他行不套用。
6. 下载原坐标的 CSV、PNG 或证据 ZIP。也可以把原照片直接交给照片准备。

`docker compose up --build -d --wait` 默认本机端口19918。在 Python 3.11 虚拟环境装好 `requirements.txt` 后也可执行 `./start.sh`。数据保存在独立数据卷或普通启动目录。
