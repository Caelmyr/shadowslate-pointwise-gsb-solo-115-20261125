# ShadowSlate 实拍投影台

用于桌面投影照片里的暗区检查。画框时保留真实桌面，避开投影物体。像素换算可使用照片里的已知标尺。

1. 打开注明为合成的练习，或导入单张 PNG、JPEG、TIFF、BMP、WebP。
2. 设定原片测量框和暗区亮度上限。当前暗区为框内达到该亮度阈的像素。
3. 直接填原片行，或用「取读数行」在图上定位。保存后查看实际行亮度与暗区覆盖。
4. 下载原坐标的 CSV、PNG 或证据 ZIP。也可以把原照片直接交给照片准备。

## 双卡共同暗区

同一桌面两次布光、只有小幅横向错位的两张照片，可以建立双卡对照：

1. 打开当前卡，在「同桌面另一张投影卡」里选另一张已存卡。两张照片高度相同，且测量框上、下行一致。
2. 配准只允许对照卡横移 ±12 个原片像素的整数位置，分别用两卡测量框最上、最下各 8 行里的真实纸面纹理比对，两条参照都必须有真实纹理支持；落在图外的像素不补。
3. 纹理在多个位置相近时，结合上下两处实见贴合，并在近似位置里选移动最少的一个；完整 SAD 评分表随接口返回。
4. 共同暗区只在夹于两条参照条之间、两张都有真实像素的重合区内，按两卡各自的暗区阈判定“两次都暗”。
5. 点读当前卡原片时同时给出另一张的真实 X/Y、两次各自暗亮；缺一边（图外或框外）即标为留待核。
6. 双卡 PNG 校样把同一次共同暗区标在两张照片上；两张照片本身和各自的正常单张读数、校样保持不变。

「双灯练习对」会生成带已知横移和不同灯光的两张合成照片，用于核对整套流程。

`docker compose up --build -d --wait` 默认本机端口19918。在 Python 3.11 虚拟环境装好 `requirements.txt` 后也可执行 `./start.sh`。数据保存在独立数据卷或普通启动目录。
